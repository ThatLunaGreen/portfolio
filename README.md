# Luna Ye · Portfolio

Explore my work and ideas in marketing, AI and storytelling—and get to know me along the way.

Public visitor website, with six pages: Infinite Canvas, Home, About Me, Selected Work, Creator Practice and Contact.

Cloudflare Pages: deploy the GitHub `main` branch from `/ (root)`. This static site requires no build step or external JavaScript CDN.

To preview, run `python3 -m http.server 8898` in this folder and open http://localhost:8898/.

The contact form submits to Formspree, where visitors complete the hosted CAPTCHA and then see Formspree's thank-you page. You can also email lunagreen105@gmail.com directly.

Source edits are maintained in the private local visual editor. Regenerate this public package after saving the latest project JSON. Keep reference photos, editor backups and complete project JSON out of this public repository.

Third-party notices: see THIRD_PARTY_NOTICES.md.

Performance: display-sized WebP derivatives, full-glyph WOFF2 fonts, pre-baked effects, prioritized first-screen images, deferred offscreen media, progressive Cover initialization and paused Cover reuse. Original assets remain in the local authoring project. Content-addressed binary assets use long-lived Cloudflare browser caching.
